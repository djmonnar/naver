네이버 예약 자동 연동
▼

고객이 네이버에서 예약하면 우리 시스템이 자동으로 감지해서 DB에 저장해요. 아무것도 안 해도 돼요! 🎉

1
고객이 네이버에서 예약 신청
네이버 플레이스 → 예약 버튼 → 날짜/시간/인원 선택
2
우리가 예약 확정
스마트플레이스 앱에서 예약 수락 버튼 누르기
💡 확정해야만 이메일이 오고 DB에 저장돼요. 접수 상태는 저장 안 됨!
3
확정 이메일 자동 감지
서버가 10분마다 Gmail을 체크해서 자동으로 파싱해요
4
DB 자동 저장
예약 관리 페이지에 📍 네이버예약 표시로 자동 등록
💡 이름이 서*승님처럼 가려져요. 실제 이름은 스마트플레이스에서 확인하세요.
⚠️ 주의사항
  • 취소하면 자동으로 DB에서 삭제돼요
  • 변경하면 기존 예약 삭제 + 새 예약 추가
  • 최대 10분 지연될 수 있어요
💬
카카오 공유방 예약 입력
▼

공유방에서 정해진 형식으로 입력하면 챗봇이 자동으로 파싱해서 DB에 저장해요.

📝 기본 입력 형식
월/일 요일 시간 이름님 인원인 메뉴 예) 4/5 토 6:00 홍길동님 4인 시그 예) 3/28 토 12:30 김영희님 10.2인 스페셜 세트1
※ 소수점 인원: 10.2인 = 어른 10명 + 어린이 2명
✏️ 특수 입력 예시
사시미 추가
3/14 토 6:00 윤동환님 4인 시그 사추2
→ 사추2 = 사시미 추가 2명분 (기본은 전원)
우니 추가
3/19 목 12:30 임성준님 2인 스시 우추
→ 우추 = 우니 추가
메뉴 미정
3/19 목 12:00 조진한님 2인 미정
→ 코스를 아직 못 정한 경우
취소
3/26 목 6:30 김종철님 12인 시그 취소
→ 메시지 끝에 '취소' 붙이기
어린이세트
4/4 토 12:30 박성은님 10.4인 시그 세트2
→ 세트2 = 어린이세트 2개
💡 수정도 자동!

같은 날짜 + 같은 이름으로 다시 입력하면 자동으로 수정돼요. 새로 추가되는 게 아니에요!
